# 功能矩阵

状态取值：`done`、`partial`、`compromise`、`not done`。

`done` 必须在「验证」列写出 pytest 或 Playwright 用例。原版有界面的行，`done` 还要有 Playwright。原版没有界面的行，pytest 即证据，验证列写明「无原版界面，后端测试即证据」并给出原版路径。没有这类证据的实现降为 `partial`。`compromise` 的说明必须包含原因和替代，编号对应 [compat.md](compat.md)。

原版路径相对于 [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) 仓库根目录。
